- 三部分分別設定題數；不重複抽取，再混合打亂。

## 題庫

## 使用與更新

無須安裝套件，直接開啟 index.html 即可。GitHub Pages 設定為 main 分支 / (root)，提交更新後自動發布。

questions.json 為可編輯題庫；更新後執行 `node scripts/sync-bank.cjs` 產生 questions.js，再一併提交。每題 id、original、answer 與 text 應完整保留。

瀏覽器朗讀使用裝置的 Web Speech API；語音品質依裝置已安裝的中文語音而異。請保持頁面開啟與裝置喚醒，手機鎖定或背景分頁可能中斷語音。

## v1.1 低視能列印排版

依「考題排版參考.docx」設定 A4 直式、20 pt 粗體新細明體、單選／姓名欄、續行縮排及題間距。保留題尾 *原題號；部分代碼在畫面與答案表顯示。題目盡量完整留在同一頁。

列印請選 A4、100% 原始大小，關閉瀏覽器頁首與頁尾，讓樣式表的邊界生效。可另存 PDF。

文字檔改用同款題號括號、明確換行、縮排及題間空行；TXT 不支援字型、字級、粗體或紙張設定，因此新增 Word 可開啟的 RTF 大字版。RTF 保留 20 pt、粗體、紙張與邊界，無須額外套件。裝置缺少新細明體時會使用替代字型，換行或頁數可能略有差異。
